# Basarbok-arket (ca. 3 minutter)

Bokarket: https://docs.google.com/spreadsheets/d/1nuOVjf-6KGV8b2cKaf39g7BK8bDyOZuwVqKxwI6NBjA/edit

1. Åpne **bokarket** (ikke hovedarket). Velg **Utvidelser → Apps Script**.
2. Marker alt i `Kode.gs`, slett, og lim inn innholdet fra
   https://raw.githubusercontent.com/kautokeinoil/basar/main/apps-script/bokark/Bokark.gs. Klikk **Lagre**.
   (Her trengs ingen `appsscript.json`.)
3. Last inn bokarket på nytt. Menyen **Basarbøker** dukker opp.
4. Velg **Basarbøker → Lag faner** og godkjenn tilgang som sist.
5. I fanen **Oversikt**: står det `#REF!`, klikk på A1 og velg **Tillat tilgang**. Gjøres én gang.

Fanene Basarbok 1–12 og Årer viser nå gevinstene som er lagt i hver bok, med statusfarge.
De oppdaterer seg selv når hovedarket synker (hvert 5. minutt). Avviste gevinster vises ikke.

Ikke skriv i fanene med formler. Egne notater kan stå i kolonner til høyre (fra F og utover),
men husk at radene flytter seg når nye gevinster kommer til.
